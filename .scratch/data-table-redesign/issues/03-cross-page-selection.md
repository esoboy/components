# 03: 跨页多选与批量工具栏

## What to build

启用多选后，用户可选择当前页记录并跨页累积选择，应用通过插槽定义批量操作。

## Blocked by

- 02 分页列表与表头排序

**Status** resolved

## 验收清单

- [x] 关闭多选时隐藏选择框与批量工具栏。
- [x] 全选和取消全选只影响当前页可见且可选的行。翻页、排序和调整每页条数保留选择。
- [x] 工具栏在有选择时显示已选数量和清除入口，插槽按钮由页面执行。

验证记录。Feature 覆盖按表格选择字段清除、选择计数和页面 slot。最终跨页 Chromium 回归由 08 覆盖。

后续调整。批量工具栏固定在视口底部，已选状态和页面操作分区，窄屏可换行。桌面和手机宽度的 Chromium 回归覆盖滚动、两表同时选择和分别清除。
