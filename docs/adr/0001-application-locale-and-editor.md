# 宿主应用的语言环境与 Tiptap 编辑器

Laravel 宿主应用负责选择语言，并在首屏请求和后续 Livewire 请求中恢复应用语言。组件库消费当前语言环境和翻译资源。组件库随包发布的中文翻译使用 `cn`。宿主使用 `zh` 或 `zh_CN` 时，由应用决定语言映射与回退策略。后续组件库审查按此约定跳过语言标识目录差异和跨请求恢复。

Editor 整个组件由外部 Tiptap 提供，包括编辑区域、工具栏、菜单、内部 DOM 和随编辑器发布的样式。后续 Blade、Livewire、Alpine 和 Tailwind 分工审查跳过 Tiptap 内部实现。组件库仍需验证对宿主表单公开的接口，包括值绑定、序列化、必填校验、重置和无障碍属性传递。
