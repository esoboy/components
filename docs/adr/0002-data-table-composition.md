# 页面组合数据表格的子组件

数据表格的父组件提供共同容器。表格主体、筛选工具栏、列设置、分页器、每页条数、总数和批量工具栏作为子组件由页面摆放。表格主体支持树状数据和可选的固定表头与固定列，汇总行通过子组件呈现。

筛选工具栏承载页面提供的筛选项，可分别启用次要筛选项折叠和清除筛选。多选支持跨页累计，表头全选作用于当前页可选的行。翻页、排序和调整每页条数保留选择，搜索或筛选变化时默认清空选择，页面可决定是否采用这个默认规则。批量工具栏在启用多选且有选中项时显示。

主要筛选和次要筛选分别通过插槽提供。折叠只隐藏次要筛选项，清除筛选清空全部筛选条件。可排序列使用一个表头按钮显示标题与当前方向，点击按钮打开排序菜单。

页面遍历当前结果并调用行子组件，使自定义单元格、操作列和行详情可以通过原生 Blade 插槽访问当前行。行子组件根据列定义渲染普通单元格。组件负责详情的触发和展开结构，页面提供详情内容。树状表格的子节点和本行详情可以独立展开。

表格使用单列排序。切换排序列时替换上一列，恢复默认时使用页面查询的默认顺序。搜索、筛选、排序和每页条数变化时，页面重置对应表格的页码。清除筛选同时清空搜索词和选择，保留排序及列布局。

列设置只在当前页面生效，刷新后恢复默认。隐藏和调整列顺序由列设置子组件联动表格主体，固定列不可调整。

普通表格和树状表格使用同一数据入口。树状模式由页面显式开启，表格从 `children-field` 读取嵌套记录，并据此判断每行是否有子节点。页面通过表格提供的遍历入口保留一层循环和原生行插槽。父子行独立选择，折叠保留已选子行。

汇总由页面计算。汇总行子组件按列键显示页面提供的值，跟随当前列的显隐和顺序。
