# Domain Docs

当前仓库采用 single-context 布局。

## 探索代码前

- 如果根目录 GLOSSARY.md 存在，先读取并使用其中的术语。
- 如果 docs/adr/ 存在，读取与当前工作相关的决策记录。
- 文件不存在时直接继续，不要求提前创建空文档。

## 文档位置

- 领域术语：根目录 GLOSSARY.md。
- 架构决策：根目录 docs/adr/。
- 组件库和演示应用共享上述领域文档。

## 使用规则

- 工单、设计、代码说明使用术语表中已有的概念名称。
- 遇到尚未定义的概念，先检查现有代码用语，避免自行发明同义词。
- 方案与现有 ADR 冲突时，明确指出冲突和理由，不静默覆盖。
- 仅在实际明确术语或形成决策时补充对应文档。
